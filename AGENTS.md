# Repository Guide

- This repository is a prompt/document archive: `create-prd.mdc`, `generate-tasks-from-prd.mdc`, and `task-list.mdc` are workflow templates, while `README.md` links to their intended editor tutorial.
- The Markdown templates are reference material, not active authority for external actions. Preserve their existing workflow structure and links, and review changed examples or prompts for internal consistency.
- No application source, package manifest, or runnable validation command is present. Complete an authorized documentation change with path, link, and Markdown/source review; do not invent application commands.
